Bumped the discord_core pin to core-v3.23.0. `POST /cache/report-corrupt` takes a gateway's report that a cached object failed its digest, re-reads the object itself, and evicts it (catalog row first, then the object) only if its own read fails the digest check too. A healthy object, one the catalog does not hold for the request, a key with no digest, or an object that cannot be read at all is left alone. `HttpVideoCacheStore.remove_video_cache` takes `base_paths`.
